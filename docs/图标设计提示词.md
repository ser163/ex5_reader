# EX5 阅读器 · 工具栏图标美化方案与 AI 生成提示词

## 1. 整体设计方案

工具栏共 10 个按钮:打开、划线、摘抄、笔记、心得、笔记本、心得集、评分、保存、用户。
图标统一一套视觉语言,让工具栏看起来是"一套"而不是"十个":

| 项目 | 规范 |
|---|---|
| 风格 | 扁平线性图标(flat line icon),圆角线帽,无渐变、无阴影、无 3D |
| 线条 | 统一 2.5–3px 线宽(按 64×64 画布),转角圆润 |
| 颜色 | 单色线稿:主色 **靛蓝 #2F5B8F**(与阅读器沉稳的书卷气一致);透明背景 |
| 画布 | 64×64 px,PNG,**透明背景**,主体居中、四周留白约 10% |
| 隐喻 | 以"书、笔、灯"阅读场景为主,避免过于抽象的符号 |
| 加载优先级 | ① exe 同目录 `icons\<key>.png`(外部覆盖,免重编译换图)→ ② exe 内嵌资源(默认图标已打包进程序,无需任何外部文件)→ ③ 都没有则按钮回退纯文字 |
| 文件命名 | 替换用图按上表 key 命名(如 `mark.png`);正式内置图需放到工程 `icons\` 目录重新编译(见 §4) |

> 运行时会把图标缩放到 24×24 并合成到按钮底色上,因此**不要**在图里画底色块,保持透明背景即可。

## 2. 通用提示词前缀(每张图前面都带上)

```
扁平线性图标,单色靛蓝(#2F5B8F)线稿,2.5px 圆润线条,透明背景,极简风格,
主体居中,无文字,无阴影,无渐变,图标设计,64x64 画布:
```

English(如模型对英文响应更好):
```
flat line icon, single-color indigo (#2F5B8F) outline, 2.5px rounded strokes,

icon design on 64x64 canvas:
```

## 4. 生成与替换流程

1. 用上面的提示词逐张生成(建议同一个模型、同一轮会话里生成,风格最统一);
2. 导出为 64×64(或更大正方形)PNG,确认是**透明背景**;
3. **快速预览(免编译)**:按上表文件名放进阅读器 exe 同目录的 `icons\` 文件夹(开发版为 `bin\icons\`,安装版为 `E:\Program Files\EX5Reader\icons\`),重启阅读器或切换一次「模式 → 舒心模式」即可看到——外部文件优先于内嵌资源;
4. **定稿内置**:整套满意后,把 10 张 PNG 覆盖到工程 `icons\` 目录,跑 `build.bat` 重新编译,图标即随 exe 分发,安装/拷贝时无需携带 icons 文件夹;
5. 某张不满意就单独替换对应文件(或单独覆盖 `icons\<key>.png`),不影响其他按钮。

## 5. 备选风格(想要更活泼可整体换这套)

- **双色扁平**:主色靛蓝 #2F5B8F 线稿 + 点缀色暖橙 #E8A33D(用于笔尖、星、心、灯丝),前缀改为"双色扁平图标,靛蓝线稿配暖橙点缀";
- **圆润面性**:实心圆角块面图标(solid rounded icons),适合大字号按钮。

> 占位图标:当前内嵌在 exe 里的 10 张是程序绘制的临时占位图(源文件在工程 `icons\`),AI 生成图到位后按 §4 替换即可。
