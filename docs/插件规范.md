# EX5 阅读器插件规范

版本:1.0(API 版本 `EX5_PLUGIN_API_VERSION = 1`)
适用程序:EX5 阅读器 GUI 版(`ex5reader_gui.exe`,x64)

---

## 1. 插件是什么

插件是一个 **Windows x64 DLL**,放在阅读器 exe 同目录的 **`plugins\`** 子目录下:

```
EX5Reader\
├─ ex5reader_gui.exe
├─ plugins\
│  ├─ demo_stats.dll      ← 你的插件
│  └─ ...
```

阅读器启动时自动扫描 `plugins\*.dll`,校验通过后把插件名称挂到菜单栏 **「插件(&P)」** 下。用户点击菜单项,即调用插件的 `Ex5PluginRun()`。

## 2. 插件必须导出的函数

插件只需包含公开头文件 **`src/ex5_plugin.h`**,并导出以下 **C 链接**函数(C++ 请用 `extern "C"` 或 `__declspec(dllexport)` + C 签名):

| 函数 | 时机 | 说明 |
|---|---|---|
| `BOOL WINAPI Ex5PluginQuery(Ex5PluginInfo* info)` | 加载时 | 填写插件信息。返回 `FALSE` 放弃加载 |
| `BOOL WINAPI Ex5PluginInit(const Ex5HostApi* host)` | 加载时 | 宿主能力表传入,可保存指针长期使用。返回 `FALSE` 放弃加载 |
| `void WINAPI Ex5PluginRun(void)` | 用户点击菜单 | 插件主入口 |
| `void WINAPI Ex5PluginShutdown(void)` | 阅读器退出前 | **可选**,释放资源 |

```cpp
// 最小骨架
#include "ex5_plugin.h"

static const Ex5HostApi* g_host = nullptr;

__declspec(dllexport) BOOL WINAPI Ex5PluginQuery(Ex5PluginInfo* info) {
    info->apiVersion  = EX5_PLUGIN_API_VERSION;   // 必填,版本不符宿主会拒绝加载
    info->name        = L"我的插件";               // 必填,显示在「插件」菜单
    info->version     = L"1.0";
    info->author      = L"Your Name";
    info->description = L"一句话说明";
    return TRUE;
}
__declspec(dllexport) BOOL WINAPI Ex5PluginInit(const Ex5HostApi* host) {
    if (!host || host->apiVersion != EX5_PLUGIN_API_VERSION) return FALSE;
    g_host = host;
    return TRUE;
}
__declspec(dllexport) void WINAPI Ex5PluginRun(void) {
    g_host->messageBox(L"Hello", L"我的插件", MB_ICONINFORMATION);
}
```

## 3. 宿主能力(Ex5HostApi)

| 成员 | 说明 |
|---|---|
| `mainWindow()` | 主窗口句柄,可作为自建对话框/窗口的父窗口 |
| `bookPath()` | 当前 `.ex5` 文件完整路径;**未打开书时返回 `NULL`,调用前必须判空** |
| `bookTitle()` | 书名(UTF-16);未打开返回 `NULL` |
| `chapterCount()` | 章节总数 |
| `currentChapter()` | 当前章节 index(协议 chapters.json 的 index) |
| `noteCount()` | 当前用户的划线 + 摘抄 + 笔记总条数 |
| `inspirationCount()` | 当前用户的心得条数 |
| `setStatus(text)` | 在主窗口状态栏显示一句话 |
| `messageBox(text, title, flags)` | 以主窗口为父窗口弹出提示框,返回 `MessageBox` 的结果 |

## 4. 规则与约束

1. **线程**:所有插件函数都在阅读器主线程(UI 线程)调用。不要在里面做长耗时操作;需要后台工作请自建线程,回 UI 时用 `PostMessage` 到 `mainWindow()`。
2. **生命周期**:`Ex5HostApi` 指针在进程内长期有效,可在 `Run` 之后继续使用(例如自定义窗口的回调里)。`Shutdown` 之后不得再访问。
3. **数据归属**:插件通过能力表拿到的是**只读快照**(数值/字符串)。写书库请直接操作 `.ex5`(ZIP + SQLite,见 RFC EX5-001),并注意与阅读器打开的句柄冲突——建议插件只做读取与展示。
4. **兼容性**:`apiVersion` 不一致时宿主拒绝加载。API 向后兼容演进,新增能力会追加在 `Ex5HostApi` 末尾并递增版本号。
5. **依赖**:插件 DLL 自身依赖(除系统 DLL 与 VC 运行库外)请一并放入 `plugins\`。
6. **命名**:文件名任意,扩展名 `.dll`;多个插件按文件名顺序加载,菜单顺序相同。

## 5. 编译(MSVC)

```bat
cl /nologo /std:c++17 /EHsc /O2 /utf-8 /LD myplugin.cpp /Fe:plugins\myplugin.dll /link user32.lib
```

把产物放进 `plugins\` 即可,无需注册。
