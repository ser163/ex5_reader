# EX5 阅读器 产品文档

- **产品名称**:EX5 Reader(ex5reader)
- **版本**:1.0.0
- **协议符合性**:RFC EX5-001《.ex5 File Format Specification, Version 1.0》
- **运行平台**:Windows(x64,MSVC 2022 编译)
- **文档日期**:2026-08-12

---

## 1. 产品概述

EX5 Reader 是一款符合 RFC EX5-001 协议的电子书阅读器。`.ex5` 是一种基于 ZIP 容器的电子书格式,封装了书籍内容(JSON 元数据 + 资源文件)与用户数据(SQLite 数据库),天然支持"书与人"的数据共存——阅读进度、划线、笔记、摘抄、心得、书评、评分全部随书携带。

本产品是协议的一个完整 C++ 参考实现:单文件可执行程序,零外部依赖,开箱即用。提供两种形态,均为 **64 位(x64)** 程序:

- **`bin\ex5reader.exe`** — 命令行版(CLI),适合脚本化与协议调试;
- **`bin\ex5reader_gui.exe`** — 图形界面版(GUI,Win32 原生),鼠标选文划线、黄色高亮渲染,适合日常阅读。

### 1.1 解决的问题

传统电子书格式把"书的内容"和"读者的痕迹"分开存放(阅读器私有数据库),换设备、换软件即丢失。EX5 协议把用户数据内嵌进书文件本身,本阅读器验证并落地了这一理念:**你的划线与心得,永远跟着书走**。

### 1.2 目标用户

- 需要深度阅读并留存批注的读者
- 希望验证 / 对接 EX5 协议的开发者
- 需要在无网络环境离线使用的场景

### 2.1 存储约定(协议之上的应用层约定)

协议中 `notes.type` 仅允许媒体类型枚举,不区分划线/摘抄/笔记。本阅读器采用以下字段组合约定,三者共用 `notes` 表且互不冲突:

| 类别 | range_start/end | original | content |
|---|---|---|---|
| 划线 | 有 | 划线原文 | 空或批注 |
| 摘抄 | 有 | 摘录原文 | 空(NULL) |
| 笔记 | 无(NULL) | 无(NULL) | 笔记正文 |

任何符合协议的实现均可无损读取这些记录;`original` + 偏移足以还原划线位置。

### 2.2 字符偏移

协议规定 `range_start` / `range_end` 为**字符偏移**而非字节偏移。本实现按 UTF-8 码点计算偏移,中文、英文、混排均正确(见 `src/utf8.h`)。CLI 阅读视图每 200 字符标注一次偏移区间 `[起-止]`,供划线/摘抄定位;GUI 版内部维护码点↔UTF-16 映射表,鼠标选区自动换算为协议偏移。

### 2.3 GUI 图形界面

`ex5reader_gui.exe` 为 Win32 原生 GUI(UNICODE 构建,64 位),与 CLI 共用同一套 EX5 读写层(`ex5book`):

## 3. 使用手册

### 3.1 启动

GUI 版(推荐日常阅读):

```bat
bin\ex5reader_gui.exe samples\sample_book.ex5
```

也可不带参数启动,点左上角「打开」选择 .ex5 文件。

CLI 版:

```bat
bin\ex5reader.exe samples\sample_book.ex5
```

打开后显示书名、章节数与上次阅读位置,进入 `ex5>` 交互命令行。

### 3.2 命令参考(CLI)

```
info                          书籍元数据(书名/作者/出版/字数)
chapters                      章节目录
read <章> [偏移] [字数]        阅读章节正文(自动记录进度)
mark <章> <起> <止> [批注]     划线,可附带批注
excerpt <章> <起> <止>         摘抄原文
note <章> <内容>               写笔记
think <章> <内容>              写心得
notes                         查看全部划线/摘抄/笔记
thoughts                      查看全部心得
delnote <id>                  删除一条划线/笔记/摘抄
delthink <id>                 删除一条心得
rate <1-5>                    评分(覆盖旧评分)
review <内容>                  写书评
reviews                       查看评分与书评
progress                      当前阅读进度(章节 + 全书百分比)
save                          立即保存(写回 .ex5 文件)
quit                          保存并退出
```

### 3.3 一次完整的阅读会话

```
ex5> read 1 0 120            # 从第 1 章开头读 120 字符,屏幕显示 [0-120] 等偏移标尺
ex5> mark 1 0 5 开篇点题      # 对偏移 0-5 的"风从海上来"划线并批注
ex5> excerpt 1 14 22         # 摘抄"老船长站在甲板上"
ex5> think 1 大海即人生       # 写一条心得
ex5> rate 5                  # 评 5 星
ex5> quit                    # 自动保存,数据写回 .ex5
```

## 4. 编译与构建

### 4.1 环境要求

- Windows + Visual Studio 2022(Build Tools 即可,含 MSVC x64 工具链)
- Python 3.8+(仅用于生成示例书,可选)

### 4.2 一键编译

```bat
build.bat
```

脚本自动初始化 vcvars64 环境(x64 工具链,两个产物均为 64 位),编译全部源码,目标文件输出至 `build\`,可执行文件输出至 `bin\ex5reader.exe`(CLI)与 `bin\ex5reader_gui.exe`(GUI)。

### 4.3 打包安装程序(Inno Setup)

```bat
"E:\Program Files\Inno Setup 7\ISCC.exe" installer\ex5_setup.iss
```

产出 `installer\output\ex5reader_setup_v1.0.0.exe`(约 3.1 MB):安装 GUI + CLI 两个程序、示例书、产品文档与图标;创建开始菜单与桌面快捷方式(使用 `images\ex5_reader.ico`);安装界面使用 `images\ex5_reader.png` 生成的向导位图。仅限 64 位系统安装(`ArchitecturesAllowed=x64compatible`)。

### 4.4 生成示例书(可选)

```bat
python tools\make_sample.py
```

按协议生成三章示例书《海与灯》至 `samples\sample_book.ex5`,包含完整的 `book_data/`、`resources/`、空 `read_data.db`(7 张表)与 `meta.xml`。

## 6. 技术架构

### 6.1 分层设计

```
┌──────────────────────────────────────────────────────┐
│  main.cpp(CLI)  /  gui_*.cpp(Win32 GUI,按功能拆分)  │
│  ├─ gui_main    主窗口/菜单/消息循环                  │
│  ├─ gui_reader  阅读区(流式加载/高亮/划线)          │
│  ├─ gui_panel   笔记面板(分类/跳转/删除)            │
│  ├─ gui_dialogs 笔记本/心得集编辑器、导出、用户管理   │
│  ├─ gui_style   文字样式/夜间模式/INI 配置            │
│  └─ gui_plugin  插件宿主 ──┐                          │
├────────────────────────────┼─────────────────────────┤
│  ex5book    EX5 容器读写层  │  插件层(ex5_plugin.h)   │
│  ├─ ZIP    : miniz        │  plugins\*.dll 热加载    │
│  ├─ JSON   : nlohmann/json│  菜单触发,宿主能力表     │
│  └─ SQLite : sqlite3      │                          │
├────────────────────────────┴─────────────────────────┤
│  utf8.h     字符偏移(码点级)                          │
└──────────────────────────────────────────────────────┘
```

### 6.2 第三方依赖(全部静态编译进 exe,无运行时依赖)

| 库 | 用途 | 来源 |
|---|---|---|
| miniz | ZIP 归档读写(RFC §3.1 容器要求) | richgel999/miniz |
| SQLite amalgamation | `read_data.db` 用户数据库(RFC §3.4) | sqlite.org |
| nlohmann/json | `info/chapters/resources.json` 解析(RFC §3.2) | nlohmann/json |

### 6.3 关键流程

**打开**:校验 ZIP → 解析 `meta.xml`(版本 + 加密检查)→ 解析三个 JSON → 提取 `read_data.db` 至临时工作文件 → 按 RFC §3.4 `CREATE TABLE IF NOT EXISTS` 建齐 7 张表 → 确保本地用户(`users.identifier='local'`)存在。

**保存**:提交并关闭 SQLite → 重建 ZIP(逐条目复制,替换 `read_data.db`,其余字节级保持不变)→ 原子替换原文件 → 重开数据库恢复会话。

**进度记录**:`history.progress` 存 JSON 位置摘要 `{"chapter":3,"offset":128}`(RFC §3.4.2 推荐做法);`records.progress` 存 0–100 数值百分比(RFC §3.4.3),两者职责分离,与协议注释一致。

**多用户**:`users` 表支持多账户(RFC §3.4.1)。新建用户时 `identifier` 取用户名(UNIQUE 约束,重名报错);密码以 **16 字节随机盐(BCryptGenRandom)+ SHA-256(salt‖password)** 共 48 字节存入 `cipher` BLOB,校验采用常量时间比较,不明文存密码;无密码用户 `cipher` 为 NULL。`notes` / `inspiration` / `reviews` / `ratings` / `history` / `records` 各表均带 `user_id`,切换用户即切换全部个人数据视图。CLI 固定使用内置 `local` 用户(显示名「本地读者」),GUI 可自由新建/切换。

### 6.4 插件体系

阅读器支持 DLL 插件扩展,为后续功能(翻译、朗读、云同步、主题等)预留标准接口:

- **加载方式**:启动时扫描 exe 同目录 `plugins\*.dll`,校验导出函数后热加载,无需重启主程序以外的任何配置;
- **接口形态**:插件导出 `Ex5PluginQuery`(信息)/ `Ex5PluginInit`(接收宿主能力表)/ `Ex5PluginRun`(菜单点击执行),可选 `Ex5PluginShutdown`;C 链接、API 版本号校验,不兼容版本直接跳过;
- **宿主能力**(`Ex5HostApi`):主窗口句柄、当前书籍路径/书名/章节数/当前章节、笔记与心得条数、状态栏输出、以主窗口为父窗口的提示框;
- **菜单集成**:加载成功的插件按名称追加到菜单栏「插件」下,点击即调用 `Ex5PluginRun`;
- **随产品附带**:demo 插件「阅读统计」(`plugins/demo/plugin_demo.cpp`,统计当前书章节与记录数量)、开发规范文档 `docs/插件规范.md`、SDK 头文件 `src/ex5_plugin.h`。第三方只需包含该头文件即可开发新插件。

## 7. 协议符合性验证

已通过与协议文档 Python 参考实现的**双向互操作验证**:

1. 本阅读器读取 Python 生成的示例书 —— 正常;
2. Python 参考代码读取本阅读器写出的 .ex5 —— 7 张表结构、notes/inspiration/ratings/history/records 全部字段完全符合 RFC §3.4 schema;
3. 归档结构(`book_data/`、`resources/`、`read_data.db`、`meta.xml`)符合 RFC §2.1;
4. 资源 ID 区间约定(901–1001000 为内容资源)符合 RFC §3.2.3;
5. 加密文件(`encrypt_scope` 1–7)按 RFC §4.1 建议拒绝解析并明确报错。

## 8. 限制与路线图

### 当前限制

- 不支持 AES-256 加密文件的解密(`encrypt_scope != 0` 明确报错)
- 未实现 RFC §5 远程同步(RESTful API)
- 多媒体资源(image/video/sound)可识别元数据,正文渲染仅支持 txt/html
- GUI 划线渲染基于 UTF-16 位置与码点偏移的映射,含 BMP 外字符(如部分生僻字)的正文高亮可能有细微偏移
